## Algorithm Flowchart - Curfew Detection

```
                    ┌─────────────────────────┐
                    │   is_curfew(current)    │
                    └───────────┬─────────────┘
                                │
                                ▼
                    ┌─────────────────────────┐
                    │ Parse curfew start/end  │
                    │ e.g., 22:00 → 1320 min  │
                    │       06:00 → 360 min   │
                    └───────────┬─────────────┘
                                │
                                ▼
                    ┌─────────────────────────┐
                    │ start_min > end_min?    │
                    │ (overnight curfew)      │
                    └───────────┬─────────────┘
                           Yes/ \No
                             /   \
                            ▼     ▼
        ┌───────────────────────┐   ┌───────────────────────┐
        │    OVERNIGHT CURFEW   │   │    SAME-DAY CURFEW    │
        │    (e.g., 22:00-06:00)│   │    (e.g., 13:00-14:00)│
        └───────────┬───────────┘   └───────────┬───────────┘
                    │                           │
                    ▼                           ▼
        ┌───────────────────────┐   ┌───────────────────────┐
        │ current >= start      │   │ current >= start      │
        │    OR                 │   │   AND                 │
        │ current < end         │   │ current < end         │
        └───────────┬───────────┘   └───────────┬───────────┘
                    │                           │
                    ▼                           ▼
        ┌───────────────────────┐   ┌───────────────────────┐
        │  Example:             │   │  Example:             │
        │  22:00 ≤ 23:30 ✓      │   │  13:00 ≤ 13:30 ✓      │
        │  03:00 < 06:00 ✓      │   │  13:30 < 14:00 ✓      │
        │  12:00 >= 22:00 ✗     │   │  15:00 >= 14:00 ✗     │
        │  12:00 < 06:00 ✗      │   │                       │
        └───────────┬───────────┘   └───────────┬───────────┘
                    │                           │
                    └─────────┬─────────────────┘
                              │
                              ▼
                    ┌─────────────────────────┐
                    │  Return: true/false     │
                    └─────────────────────────┘
```

## Web UI State Machine

```
                              ┌─────────────────┐
                              │     LOADING     │
                              │   (app start)   │
                              └────────┬────────┘
                                       │
                            Fetch /api/status
                            Fetch /api/schedule
                            Fetch /api/focus
                                       │
                    ┌──────────────────┼──────────────────┐
                    │                  │                  │
                    ▼                  ▼                  ▼
           ┌─────────────────┐ ┌─────────────────┐ ┌─────────────────┐
           │   FOCUS MODE    │ │   LOCKED MODE   │ │    EDIT MODE    │
           │                 │ │                 │ │                 │
           │ • Timer display │ │ • Progress bar  │ │ • Day schedule  │
           │ • Progress bar  │ │ • Countdown     │ │ • Lock duration │
           │ • Cannot cancel │ │ • Timeline      │ │ • Presets       │
           └────────┬────────┘ │ • Cannot edit   │ │ • Focus options │
                    │          └────────┬────────┘ └────────┬────────┘
                    │                   │                   │
               Timer ends          Lock expires      Click "Lock It In"
                    │                   │                   │
                    │                   │                   ▼
                    │                   │          ┌─────────────────┐
                    │                   │          │ PASSWORD MODAL  │

## File Permissions During Lock

```
┌─────────────────────────────────────────────────────────────┐
│                    UNLOCKED STATE                            │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  schedule.json                                               │

│  ├── Group: staff                                            │

│  └── Status: User can edit via Web UI or directly           │
│                                                              │
└─────────────────────────────────────────────────────────────┘
                              │
                    POST /api/activate
                    (with password)
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                     LOCKED STATE                             │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  schedule.json                                               │
│  ├── Owner: root         ◄── Daemon changes ownership       │
│  ├── Group: wheel                                            │
│  ├── Mode: 644 (rw-r--r--)                                   │
│  └── Status: User cannot edit (no write permission)         │
│                                                              │
│  .lock-password                                              │
│  └── Contains: bcrypt hash (e.g., $2b$10$...)               │
│                                                              │

                              │
                    Lock period expires
                    (lockEndDate < now)
                              │
                              ▼

│                    UNLOCKED STATE                            │
│                  (ownership restored)                        │
└─────────────────────────────────────────────────────────────┘
