## What We Did This Session

### 1. Debugged Focus Mode Not Working
**Problem:** User activated 5-min focus mode, machine didn't lock down during the session.

**Root Cause:** Conflicting daemon installations from older NightOwl versions:
- Old `com.nightowl.ui.plist` pointed to `/usr/local/share/nightowl/ui/server.js`
- Old UI installed at `/usr/local/share/nightowl/ui/`
- Previous project versions existed at `~/nightowl/` and `~/nightowl-v3/`

**Resolution:**
```bash
sudo launchctl unload /Library/LaunchDaemons/com.nightowl.ui.plist
sudo rm /Library/LaunchDaemons/com.nightowl.ui.plist
sudo rm -rf /usr/local/share/nightowl
```

### 2. Discovered Focus Mode Actually Worked
After cleanup and reviewing logs at `/var/log/nightowl.log`, we found:
```
[2026-02-26 14:53:01] FOCUS MODE: 3 seconds remaining
[2026-02-26 14:53:01] === CURFEW ENFORCEMENT (immediate) ===
[2026-02-26 14:53:04] Force-killing all processes for user: asmeedhungana
[2026-02-26 14:53:14] Initiating system shutdown
```
The machine WAS shut down - user rebooted after focus period expired.

### 3. Added Idle Logging to Daemon
**Problem:** Daemon was silent when no schedule/focus active, making it hard to verify it's running.

**Fix:** Added logging in main loop:
- `nightowld.sh`: Now logs `[HH:MM:SS] Idle — no active schedule or focus mode` every 60s

### 4. Fixed Missing NIGHTOWL_FOCUS in Install Script
**Problem:** `nightowl.sh` install command wasn't setting `NIGHTOWL_FOCUS` env var in the daemon plist.

**Fix:** Added `NIGHTOWL_FOCUS` to the plist template in `cmd_install()`.
